# 无障碍用户使用指南

## 离线可访问多模态本地内容检索系统 (Offline Accessible Multimodal Local Content Retrieval System)

| 项目 | 详细信息 |
|---|---|
| 项目阶段 | 第 5 周 - 跨平台 UI 开发与无障碍支持 |
| 应用程序 | 离线可访问多模态本地内容检索系统 |
| 验证平台 | Microsoft Windows 桌面端 |
| 界面框架 | Flutter 3.44.4 stable |
| 指南版本 | 1.0 |

## 1. 简介

“离线可访问多模态本地内容检索系统”允许用户添加本地文档与图像，自动构建本地索引，并在已索引的内容中进行高效检索。

本系统所有文件解析、向量索引构建与检索推理全流程均在**本地离线**完成。系统内置了完善的无障碍特性，专为纯键盘用户、屏幕阅读器（盲人读屏软件）用户，以及需要高对比度或大字号视觉辅助的用户进行了深度适配。

本指南详细介绍：

- 如何在应用中进行全局导航
- 如何添加与管理本地知识库文件
- 如何检索文档与图片
- 如何使用键盘快捷键高效操作
- 如何在 Windows 下配合 NVDA 屏幕阅读器使用
- 如何开启高对比度模式
- 如何放大或缩小系统字号

## 2. 支持的文件格式

文件库（File Library）选择器支持以下文件格式：

### 文本与文档格式

- 纯文本：`.txt`
- PDF 文档：`.pdf`
- Word 文档：`.docx`

### 图像格式

- PNG：`.png`
- JPEG：`.jpg` 与 `.jpeg`
- 位图：`.bmp`
- WebP：`.webp`

不支持的文件格式在系统文件选择弹窗中会自动过滤或置灰。

## 3. 启动应用程序

在当前的开发调试环境下，在 Flutter 项目根目录打开终端并执行：

```powershell
flutter run -d windows
```

等待应用程序窗口启动并完成底层初始化。

如果是已打包好的 Windows Release 安装包，直接双击运行提供的 `.exe` 可执行程序即可。

## 4. 应用界面布局

系统主要包含三大一级功能模块：

1. **文件库** - 本地文档与图片管理
2. **搜索** - 多模态内容检索
3. **设置** - 无障碍与视觉外观配置

在宽屏桌面窗口下，这三个入口位于窗口左侧的侧边导航栏（Navigation Rail）中。

当前选中的模块具有高亮视觉提示。纯键盘用户可随时使用下方介绍的全局快捷键快速切页。

## 5. 键盘快捷键一览表

| 快捷键 | 触发动作 |
|---|---|
| `Alt+1` | 打开“文件库”页面 |
| `Alt+2` | 打开“搜索”页面 |
| `Alt+3` | 打开“设置”页面 |
| `Ctrl+F` | 快速打开“搜索”页面并将输入焦点自动置于搜索框中 |
| `Tab` | 焦点移动至下一个可交互控件 |
| `Shift+Tab` | 焦点逆向移动至上一个可交互控件 |
| `Enter` | 激活并触发当前处于焦点的按钮或操作 |
| `Space` (空格键) | 激活并触发当前处于焦点的按钮、开关或操作 |

全局导航快捷键在鼠标点击页面任何区域后依然持续生效。

## 6. 使用文件库

### 6.1 打开文件库

在左侧导航栏点击 **文件库**，或直接按下键盘快捷键 `Alt+1`。

页面主标题为 **本地文件库**。

如果尚未导入任何文件，界面会显示空文件库的占位提示信息。

### 6.2 添加与导入文件

1. 打开“文件库”页面。
2. 点击或通过键盘激活 **添加文件** 按钮。
3. 在弹出的 Windows 系统文件选择器中选取一个或多个支持的文件。
4. 点击确认。
5. 等待系统在后台自动完成文件文本提取、图像向量化与索引构建。
6. 观察界面上的状态提示文字，确认索引构建是否成功完成。

文件选择器支持按住 `Ctrl` 或 `Shift` 单次批量导入多个文件。

*提示：索引正在构建时，请勿中途强制关闭应用程序。*

### 6.3 重新索引文件

当本地文件内容发生修改或更新后，可对其重新构建索引：

1. 在文件库列表中找到目标文件。
2. 打开该文件的管理操作菜单。
3. 选择 **重新索引**。
4. 等待界面提示更新完成。

重新索引会使用该文件当前最新的内容覆盖并替换旧的向量与关键词索引记录。

### 6.4 删除文件索引

删除索引只会从本检索系统的数据库中移除该文件的索引条目，**绝不会删除您电脑硬盘上的原始物理文件**。

1. 在文件库列表中定位到目标文件。
2. 打开该文件的操作菜单。
3. 选择 **删除索引**。
4. 在弹出的二次确认对话框中进行核对。
5. 点击 **删除索引** 确认移除，或点击 **取消** 保留索引。

## 7. 检索本地内容

### 7.1 进入搜索界面

点击导航栏中的 **搜索**，或按下快捷键 `Alt+2`（或直接按 `Ctrl+F`）。

使用 `Ctrl+F` 会一步到位切至搜索界面并直接聚焦到输入框，方便直接打字。

页面主标题为 **搜索本地内容**。

### 7.2 执行文本文档搜索

1. 打开搜索界面。
2. 在 **搜索内容** 输入框中键入要查询的关键词或自然语言描述。
3. 在 **搜索类型** 下拉框中确认选择为 **文本文档**。
4. 点击 **搜索** 按钮或按下键盘回车。
5. 等待搜索状态提示完成。
6. 浏览下方按语义相关度排序的结果卡片。

查询词示例：

> accessibility guide (无障碍指南)

### 7.3 执行图片搜索（以文搜图）

1. 打开搜索界面。
2. 输入想要寻找的图片画面内容或特征描述。
3. 在 **搜索类型** 中选择 **图片**。
4. 点击 **搜索**。
5. 浏览系统返回的匹配图片结果列表。

建议使用描述画面主体、物体、场景颜色或视觉特征的自然语言词汇。

### 7.4 理解检索结果

每条检索结果卡片包含以下信息：

- **排序序号**（Rank number）
- **文件名称**（File name）
- **物理绝对路径**（Local file path）
- **匹配的相关段落文本或上下文摘要**（Relevant text）
- **语义相关度百分比**（Relevance percentage）

排序序号越靠前，代表检索系统评估该条目与你的查询词相关度越高。

### 7.5 清空搜索状态

点击 **清除** 按钮可一键重置当前的检索结果；输入框尾部的清除图标也可快速清空已输入的查询文本。

## 8. 无障碍设置

在导航栏中点击 **设置**，或按下快捷键 `Alt+3`。

页面主标题为 **无障碍设置**。

### 8.1 高对比度模式

**高对比度模式** 开关可将系统界面一键切换为专门适配的超高对比度视觉配色。

开启方式：

1. 打开“设置”界面。
2. 将焦点移动至 **高对比度模式** 开关（或鼠标点击）。
3. 按下 `Space`、`Enter` 或鼠标单击切换。

高对比度主题采用：

- 纯黑纯色背景
- 纯白高清晰文字
- 亮黄色重点强调与焦点轮廓
- 边界鲜明的高可见度控件

再次点击开关可随时切回标准默认主题。

### 8.2 调整文字大小

系统支持以下 5 档文字缩放比例：

- 100%（标准大小）
- 125%
- 150%
- 175%
- 200%（2倍最大放大）

操作方式：

- 点击 **减小文字** 按钮：每次将字号缩小 25%
- 点击 **增大文字** 按钮：每次将字号放大 25%

当前百分比读数直观显示在控件上方。

在 100% 极限下“减小文字”按钮自动禁用；在 200% 极限下“增大文字”按钮自动禁用。

配套的进度条向辅助技术暴露了语义滑块信息，方便读屏软件无障碍识别与操控。

## 9. 纯键盘无障碍操作指南

本系统所有核心工作流均支持脱离鼠标纯键盘操作。

### 9.1 推荐操作流程

1. 使用 `Alt+1`、`Alt+2`、`Alt+3` 快速在各个页面之间切换。
2. 按 `Tab` 键向前依次流转焦点。
3. 按 `Shift+Tab` 键逆向回退焦点。
4. 按 `Enter` 或 `Space` 激活当前选中的按钮、开关或链接。
5. 任何时候需要查资料，按 `Ctrl+F` 直达搜索输入框。

### 9.2 键盘焦点指示

获得焦点的 Material 控件均带有高亮外轮廓视觉提示。

若焦点位置不在预期，按一次 `Tab` 键即可在当前屏幕内重新寻轨，或直接按下 `Alt+1/2/3` 快速回到顶层导航。

## 10. 在 Windows 下配合 NVDA 屏幕阅读器

NVDA 是一款由 NV Access 提供的免费开源 Windows 屏幕阅读器。

官方下载地址：

<https://www.nvaccess.org/download/>

### 10.1 启动 NVDA

可通过以下任意方式启动：

- 在 Windows 开始菜单中搜索并打开 NVDA。
- 双击桌面上的 NVDA 快捷方式。
- 按下快捷键 `Ctrl+Alt+N`（若安装时已配置）。

启动 NVDA 后，切换回本检索系统应用窗口即可开始读屏。

### 10.2 常用 NVDA 快捷键

| 快捷键 | 作用说明 |
|---|---|
| `Insert+N` | 打开 NVDA 主菜单 |
| `Insert+Q` | 退出 NVDA 读屏软件 |
| `Tab` | 移动到下一个可聚焦控件并朗读 |
| `Shift+Tab` | 移动到上一个可聚焦控件并朗读 |
| `Enter` 或 `Space` | 激活当前处于焦点的控件 |

*注：根据您的 NVDA 设置，`Caps Lock`（大写锁定键）也可作为 NVDA 修饰键使用。*

### 10.3 NVDA 朗读的信息类型

本系统完整提供了以下元素的无障碍语义信息：

- 页面层级大标题
- 导航目标栏目
- 搜索输入框名称与操作按钮
- 开关当前开启/关闭状态
- 文字缩放当前百分比数值与调节动作
- 实时搜索进度与文件索引状态消息
- 结构化搜索结果卡片
- 文件管理操作按钮

关键的状态变动均接入了实时区域（Live-region）语义，状态发生变更时 NVDA 会主动语音播报。

### 10.4 配合 NVDA 调节文字大小

在设置页面中，使用 `Tab` 键移动到：

- **减小文字** 按钮
- **增大文字** 按钮

按 `Enter` 或 `Space` 即可调整字号。

同时，文字缩放进度条也完整暴露了 **文字缩放比例** 语义标签、当前读数以及增大/减小动作指令。

## 11. 离线隐私与本地安全说明

本系统在架构设计上所有核心计算均在本地硬件完成：

- 文档文本提取与图片解析
- 文本与多模态向量嵌入（Embedding）
- 向量数据库索引构建
- 关键词倒排索引
- 检索召回与结果重排

“设置”页面中专门包含了 **离线隐私** 声明，提示用户所有数据均安全驻留在本地。

在导入涉及商业秘密或高度敏感的文件时，请遵从您所在组织的安全规范。

## 12. 状态反馈与异常排查

界面会在以下操作过程中显示即时状态反馈：

- 打开文件选择器弹窗
- 取消文件选取
- 文件索引解析中
- 索引构建完成
- 切换检索类型
- 执行搜索中
- 搜索完成
- 搜索结果为空
- 操作失败与错误报错

如果某个操作报错失败：

1. 查看界面上显示的明确错误提示。
2. 确认原始文件依然存在且未被其他程序独占占用。
3. 确认文件格式属于支持的文件类型。
4. 重新尝试操作。
5. 若后台无响应，重启应用程序重试。

## 13. 无障碍故障排查

### 13.1 NVDA 未能朗读某个控件

1. 优先使用 `Tab` 键导航至该控件，避免单一依赖鼠标点击。
2. 检查并确认 NVDA 进程仍在正常运行。
3. 按 `Alt+1`、`Alt+2` 或 `Alt+3` 切到其他页面再切回来刷新焦点。
4. 若语音完全中断，尝试重启 NVDA。
5. 若无障碍树停止更新，重启 Flutter 应用程序。

### 13.2 Windows AXTree 报错

早期的原型版本因使用原生 Flutter Slider，在运行 NVDA 时可能会触发 Windows 语义树报错。

当前版本已将该控件重构为无障碍语义组件与独立步进按钮，在标准测试环境下已恢复完全正常。

若在未来升级 Flutter 引擎后再次遇到类似问题：

1. 记录当前的 Flutter 与 NVDA 版本号。
2. 记录是哪个页面和控件触发了异常。
3. 检查 NVDA 是否还能继续朗读新聚焦的控件。
4. 重启应用后继续测试，并将异常作为 Flutter Windows 引擎的潜在 Regression 问题记录反馈。

### 13.3 键盘快捷键失效

1. 确认当前应用程序窗口处于前台激活状态。
2. 尝试使用键盘左侧或右侧的修饰键（Alt/Ctrl）重新按下组合键。
3. 检查电脑上是否有其他第三方软件（如输入法、录屏软件）拦截占用了全局快捷键。
4. 作为备用手段，直接按 `Tab` 键配合导航栏完成操作。

### 13.4 界面文字过大或过小

进入“设置”页面，反复点击 **减小文字** 或 **增大文字**，直至调节到舒适的阅读比例。

### 13.5 视觉对比度不足

进入“设置”页面，开启 **高对比度模式** 开关。

## 14. 当前版本局限说明

当前原型版本存在以下已知边界：

1. 无障碍专项验证主要在 Windows + NVDA 组合下完成。
2. 读屏体验可能随 Flutter、Windows 与 NVDA 的不同版本组合存在细微差异。
3. Android TalkBack 与 Apple VoiceOver 需要在对应物理设备上进行专项测试。
4. WAVE 适用于未来的 Flutter Web 网页端部署，不适用于 Windows 原生客户端。
5. 针对海量文件的深度过滤与复杂多重排序功能将在后续版本中持续增强。

## 16. 报障时需记录的支撑信息

如需反馈系统缺陷，请尽可能附带以下信息：

- 操作系统版本号（如 Windows 11 23H2）
- Flutter 运行版本
- NVDA 版本号（如适用）
- 触发问题的具体页面
- 触发该问题的具体控件或交互动作
- 界面上显示的可视错误文本
- 终端打印的 stderr 错误日志
- 重启应用程序后问题是否依然能稳定复现
